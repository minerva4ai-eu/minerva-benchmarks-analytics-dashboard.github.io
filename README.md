# Minerva Benchmarks Analytics Dashboard

Interactive dashboard for exploring and analyzing **Minerva AI/HPC benchmark results**.

The dashboard provides visualizations and comparisons of benchmark results for **LLM inference and training** across different systems, models, frameworks, and configurations.

## What does it contain?

- **Inference benchmarks**: Analyze throughput, latency, energy efficiency, and other inference performance metrics.
- **Training benchmarks**: Explore training performance, scaling, GPU utilization, memory, energy consumption, and related metrics.
- **Interactive filters**: Filter results by system, model, framework, GPU/node configuration, and other benchmark parameters.
- **Interactive visualizations**: Compare benchmark runs through charts, scaling plots, and data tables.
- **Python analysis**: Inspect and further analyze the selected benchmark data directly in the dashboard.

The dashboard is implemented as a standalone `index.html` file and can be opened directly in a web browser.

## Related Project

Benchmarking tools and data are available in the [Minerva Benchmarks](https://github.com/minerva4ai-eu/minerva-benchmarks) repository.
